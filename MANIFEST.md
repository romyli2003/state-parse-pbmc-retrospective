# Package manifest

## Scope

Private portfolio-safe documentation of project-specific data engineering, donor-zero-shot experiment design, exploratory evaluation, Parse QC, and validation readiness.

## Included

- Seven sanitized project-specific scripts.
- Aggregate four-variant metrics and one standalone aggregate figure.
- Three standalone Parse-QC figures and a compact QC summary.
- Documentation and provenance for every retained result.

## Excluded

No matrices, source datasets, checkpoints, optimizer states, embeddings, predictions, cell-level or donor-level tables, complete DEG tables, logs, environment archives, temporary files, slides, therapeutic curation, or pharma-benchmarking material are included.

## Release status

No license is supplied. This package is a private record. Any later disclosure requires a fresh scientific, confidentiality, data-use, and dependency-license review.
