# Durable package rules

- Keep this a private, portfolio-safe record; do not imply publication or redistribution rights.
- Never add datasets, checkpoints, predictions, embeddings, full DEG tables, logs, or large result tables.
- Require a provenance entry for every metric and figure.
- Use placeholders, arguments, or environment variables instead of internal paths.
- Preserve scientific limits: exploratory comparisons are not definitive benchmarking, and validation readiness is not completed external validation.
- After changes, verify sanitization, documentation links, file sizes, and absence of prohibited artifacts.
